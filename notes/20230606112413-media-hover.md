# @media hover feature

> The hover CSS media feature can be used to test whether the user's primary input mechanism can hover over elements.

This can be handy to differentiate devices that have an 'actual' hover. Most mobile browsers apply `:hover` styling after interacting with an element, or via a long press, to support otherwise inaccessible things, like opening a menu on hover.

```css
a:hover {
  color: black;
  background: yellow;
}

@media (hover: hover) {
  /* when hover is supported */
  a:hover {
    color: white;
    background: black;
  }
}
```

Using the check above, a mobile browser would get the first block, not the second, as it should fail the `@media` check.

Not every `:hover` styling should use this `@media` check. It's mostly useful for when you're controlling actual state, changing layout, doing animations, etc. Think about what only makes sense with a pointer device.

Note that some phones will pass this check, which seems against the spec, e.g. https://www.ctrl.blog/entry/css-media-hover-samsung.html
