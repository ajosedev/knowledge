# MCP Embedded Skills

A strategy for lazy loading [[20250811104331-model-context-protocol-mcp|MCP servers]] based on the contents of a [[20260306121850-ai-agent-skills|skill]].

Helps with managing [[20260318091849-ai-context-tokens]].

Plugins exist for this like https://github.com/keybrdist/opencode-lazy-loader, but I think other harnesses do this by default.
