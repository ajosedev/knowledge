# Figma plugins

Some helpful tips for working with/creating Figma plugins.

- I've found the best flow is to create the boilerplate via Figma, then build on top of that. [[ai]] is great for creating quick Figma plugins
- `CMD + Option + P` re-runs the last plugin in [[figma]]. This can be useful for plugin development, as it will run the newest version built.
- The 'Developer VM' can be used so that developer tools (think browser) can be used to inspect the plugin: https://developers.figma.com/docs/plugins/debugging/#developer-vm
