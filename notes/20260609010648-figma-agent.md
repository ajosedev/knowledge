# Figma Agent

Figma now has the ability to use an AI agent inside of the Figma canvas.

You can do things like:
- Start a prompt from any design layer
- Parallel prompt to play out multiple ideas at once
- Make edits and iterate while the agent iterates, too

Out of all the AI releases Figma has made in 2026, this seems like the biggest one by far. It positions AI once again as a helper inside of the canvas, rather than requiring changing the entire workflow of designers. This means designers don't need to figure out [[20260413105415-models-and-harnesses]], understand things like [[20250811104331-model-context-protocol-mcp]], etc. They can just use Figma the same way they always have, sprinkling in some AI help.

As a mental model, it seems like you can do a lot of what you could with the [[20250811031606-figma-mcp]], just without leaving the canvas. From the Figma docs:
>Use Figma's agent when you're working on the canvas—it's built in and has additional context about your design system. Use the [MCP server](https://www.figma.com/blog/the-tldr-on-mcp/) and [use_figma](https://www.figma.com/blog/the-figma-canvas-is-now-open-to-agents/) to pull code onto the canvas or push designs back to code.

There's a lot more niceities though. You can reference design system elements directly, include Figma libraries, ask questions, work with comments, etc. My biggest concern is that its decision making ability is heavily influenced by information within Figma. You can connect it to an MCP, but I'm unsure how much it would lean towards finding info in Figma vs calling the MCP.
