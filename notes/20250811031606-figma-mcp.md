# Figma MCP

[[figma]] has a [[20250811104331-model-context-protocol-mcp]] server which they're investing heavily into. It helps with both [[20260617024455-generating-design]] and [[20260617024622-design-to-code]].

The MCP server does two main things to help with this:
- Extracts design context from Figma and parses it to an agent. This works a lot better than a screenshot, as it can provide more detailed mapping and informations, such as semantics.
- Interacts with the Figma canvas using its `use_figma` tool, which has access to Figma's plugin API. This allows it to generate designs for you, make changes, etc.
	- It's kind of like [[20260609010648-figma-agent]], but the capability comes from the MCP. This lets you write semi-deterministic tools outside of Figma that interacts with it.
	- https://www.figma.com/blog/the-figma-canvas-is-now-open-to-agents/

So it helps with both reading from Figma, and writing to Figma.

By default the MCP server doesn't have a good understanding of your design system. In addition, it's tailored towards React + Tailwind, which may or may not be useful for you. [[20260604114143-figma-code-connect]] (v important), [[20230622094635-figma-variables]], and other data sources help provide that information.

There's a lot of value here, but consider using it in addition to your own [[20260814111132-design-system-mcp]] to get more detailed information on standards, guidelines, etc.

As a small gotcha there's two MCP servers, a remote version and a desktop version. Figma recommends using the remote version, which is more powerful and (I think) is the only one with write support.
Historically it seemed like there was generate_designs [(Code to Canvas)](https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/) , then replaced by use_figma [(Write to Canvas)](https://developers.figma.com/docs/figma-mcp-server/write-to-canvas/).
	The latter has examples like this: "Using this Figma file: URL, create a new page and build a settings screen with auto layout using our existing components."
	The latter talks a lot more about using your design system, whereas the first link does not mention it at all.

Figma recommends using their own skills in combination with the MCP. Confusingly there's a `figma-use` skill that should be used with the `use_figma` tool.
